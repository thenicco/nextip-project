# 🪙 NexTIP - Calculadora de Gorjetas Inteligente

O **NexTIP** é um projeto desenvolvido para facilitar o cálculo de gorjetas e divisões de contas em restaurantes. Criado com foco em **Clean Code** e **Manipulação de DOM**, o projeto simula uma ferramenta real de utilidade diária.

## 🚀 Tecnologias
* HTML5 Semântico
* CSS3 (Modern Layouts)
* JavaScript (ES6+)

## 🛠️ Funcionalidades
- [x] Cálculo de porcentagem de gorjeta customizada.
- [x] Divisão de conta entre múltiplas pessoas.
- [x] Validação de inputs (evitando valores negativos ou vazios).
- [x] Layout responsivo (funciona no celular enquanto você está no restaurante).

## 📁 Como rodar o projeto
1. Clone este repositório: 
   `git clone https://github.com/SEU_USUARIO/tip-spider.git`
2. Abra o arquivo `index.html` no seu navegador.

## 🧠 Aprendizados
Este projeto foi fundamental para consolidar conceitos de:
- Escopo de funções em JavaScript.
- Eventos de formulário (`submit`, `input`).
- Lógica matemática aplicada ao desenvolvimento web.
